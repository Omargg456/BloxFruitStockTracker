# Blox Fruits Stock Tracker

1. ارفع كل الملفات (مع مجلد `.github`) إلى مستودع GitHub.
2. من **Settings → Pages**: اختر Branch `main` والمجلد `/ (root)`.
3. من **Settings → Actions → General → Workflow permissions**: اختر *Read and write permissions*.
4. من تبويب **Actions** شغّل **Update stock** يدويًا مرة واحدة (Run workflow).

بعدها يتحدث `stock_data.json` تلقائيًا كل ساعتين.
